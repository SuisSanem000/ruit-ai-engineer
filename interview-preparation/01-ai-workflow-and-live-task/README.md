# Module 1 — AI Workflow, Laptop Setup & Live Task Playbook

> **Luis's Interview 1 (45–60 mins):**  
> *"We will ask you to fire up your laptop, show us your setup and complete a brief task with AI. We will talk about it for a bit and then we will chat about some concepts ... And of course how do you work with AI: how do you use agents, skills, plugins... How do you use sessions in parallel, and so on."*

---

## 1. How to Study This Module (2 to 3 Hours Total)

- **Part 1 — Your AI Story & Harness Engineering (45 mins):**
  - Read [01-my-real-ai-story-and-daily-workflow.md](./01-my-real-ai-story-and-daily-workflow.md) — Connect QueryLaw AJV schema checks, Parsaiane 150-site crawler, and Dadroit 630K extension to your daily 5-step AI workflow. (Zero claims of RAG, fine-tuning, ML deployment, or production Python/Django).
  - Read [02-harness-engineering-step-by-step.md](./02-harness-engineering-step-by-step.md) — Master the 5-step Harness Engineering process for building features safely.
- **Part 2 — Tools, Multi-Agents & Parallel Sessions (45 mins):**
  - Read [03-antigravity-claude-code-and-copilot-flow.md](./03-antigravity-claude-code-and-copilot-flow.md) — How you use Antigravity IDE, Claude Code (in VS Code & terminal with OpenRouter token), and GitHub Copilot Code Review.
  - Read [04-multi-agents-parallel-sessions-skills-and-plugins.md](./04-multi-agents-parallel-sessions-skills-and-plugins.md) — How you use agents, skills, plugins, custom slash commands, and 3 parallel session patterns without race conditions.
- **Part 3 — Laptop Walkthrough & Live Task Playbook (30 mins):**
  - Read [05-laptop-setup-and-agentic-workflow-script.md](./05-laptop-setup-and-agentic-workflow-script.md) — 5-minute pre-interview checklist and 3-minute screen-share walkthrough script for Luis.
  - Read [06-live-ai-coding-playbook.md](./06-live-ai-coding-playbook.md) — 5-step calm playbook for the 20-minute live AI coding task.
- **Part 4 — Spoken Q&A Practice & Hands-On Sandbox (30–45 mins):**
  - Read [07-interview-qa-script-how-i-work-with-ai.md](./07-interview-qa-script-how-i-work-with-ai.md) — Practice answering the 8 interview questions out loud in Upper-B2 English.
  - Explore [live-task-sandbox/](./live-task-sandbox/) — Read [live-task-sandbox/README.md](./live-task-sandbox/README.md) and run the basic Python code and tests in [marketplace_connector.py](./live-task-sandbox/marketplace_connector.py) and [test_marketplace_connector.py](./live-task-sandbox/test_marketplace_connector.py).
